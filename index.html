3D CADの平面図から、Jw_cadの図面データ（.jww）を出力するプログラム「JW AUTO DRAW」の公式サイトです。このページは入口で、概要・対応CAD・使い方・開発の経緯は下記の各ページで公開しています。

JW AUTO DRAW について

JW AUTO DRAW は、住宅の間取り図（1/100の平面図）を読み取り、Jw_cad で開ける図面データ（.jww）を出力する、Windows 向けのプログラムです。出力は1/50平面詳細図の「下地」で、最後は人の手で仕上げることを前提にしています。

読み取りはすべてプログラムの処理だけで行い、AIは使いません。壁の位置は、まず910mmの通りを読み、次に455mm、227.5mmと段階的に細かく読むことで、家具や設備を壁と間違えないようにしています。再現性のある決まった処理で読むため、同じ入力には同じ出力が返ります。

プログラムは GitHub で無償公開しています（MITライセンス）。設定もコードも公開しているので、自分の環境に合わせて書き換えることもできます。

できること

  • 入力：ウォークインホームのプレゼンボード PDF、または平面図の PNG / JPG 画像（1/100相当）
  • 読み取り：壁（外壁・内壁）と開口部・建具を、画像から段階的に判定します
  • 対応部品：YKK AP APW430、LIXIL EW、パナソニック ベリティス など（部品データは同梱していません）
  • 出力：階ごとに .jww ファイルを出力します（1/50平面詳細図の下地）
  • 動作環境：Windows（読み取りから作図まで、すべてプログラム処理です）
